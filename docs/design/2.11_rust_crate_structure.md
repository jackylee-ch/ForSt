## 0. 文档元数据

## 1. 设计目标

### 1.1 目标

1. **职责单一**：每个 crate 只做一件事，高内聚低耦合
2. **编译隔离**：修改上层 crate 不触发底层 crate 重编译，缩短增量编译时间
3. **可选功能**：通过 feature flags 控制可选依赖（io_uring、SIMD、JNI fallback 等）
4. **测试友好**：每个 crate 可独立测试，无需启动完整引擎
5. **与五层架构对齐**：crate 划分映射到 2.1 的五层架构
6. **渐进演化**：三阶段 crate 演化路径，从核心替换到 DeltaJoin 再到 Remote Service（Remote Merge + Server-side Compaction）

### 1.2 命名规范

```
forst-rs-{layer}-{component}

示例:
  forst-rs-common      → 公共类型/错误/工具
  forst-rs-io           → Layer 1 IO
  forst-rs-storage      → Layer 2 Storage
  forst-rs-engine       → Layer 3 Engine
  forst-rs-api          → Layer 4 API trait
  forst-rs-bridge       → Layer 5 Bridge (C ABI 导出)
  forst-rs-deltajoin    → DeltaJoin 支持（中期）
  forst-rs-remote-service → Remote Merge Service + Server-side Compaction（长期）
```

## 2. Crate 总览

### 2.1 三阶段 Crate 演化

#### 短期（Short-term）：核心 crate — drop-in 替换

核心引擎 crate，作为现有 RocksDB StateBackend 的 drop-in 替换方案：

```
forst-rs/
├── Cargo.toml                  # Workspace root
├── crates/
│   ├── forst-rs-common/        # 公共类型、错误、工具宏
│   ├── forst-rs-io/            # Layer 1: 文件系统、异步 IO
│   ├── forst-rs-storage/       # Layer 2: MemTable、SST、Cache、Bloom
│   ├── forst-rs-engine/        # Layer 3: Engine 核心（get/put/flush/compact/checkpoint）
│   ├── forst-rs-api/           # Layer 4: 对外 API trait（Flink 适配 trait + DeltaJoin trait）
│   ├── forst-rs-bridge/        # Layer 5: C ABI 导出 + FFI 类型
│   ├── forst-rs-bench/         # 性能基准测试
│   └── forst-rs-test-utils/    # 测试工具和 fixtures
├── java/                       # Java 侧代码（Flink 适配层 + DeltaJoin 组件）
│   ├── forst-rs-java-bridge/   # FFM/JNI 桥接 Java 类
│   └── forst-rs-flink/         # Flink StateBackend 适配（2.9）+ DeltaJoin 本地化（2.13）
└── docs/                       # 设计文档
```

#### 中期（Mid-term）：新增 forst-rs-deltajoin crate

在核心 crate 稳定后，新增 `forst-rs-deltajoin` crate 提供 DeltaJoin 支持：

```
crates/
  └── forst-rs-deltajoin/       # DeltaJoin 支持
      ├── src/
      │   ├── lib.rs
      │   ├── delta_source.rs   # 增量数据摄入
      │   ├── local_lookup.rs   # 本地 prefix_scan Lookup
      │   ├── merge_coord.rs    # Multi DeltaJoin 协调
      │   └── state_sync.rs     # 状态同步机制
```

#### 长期（Long-term）：新增 forst-rs-remote-service crate

新增 `forst-rs-remote-service` crate 实现 Remote Merge Service 和 Server-side Compaction：

```
crates/
  └── forst-rs-remote-service/   # Remote Merge Service + Server-side Compaction
      ├── src/
      │   ├── lib.rs
      │   ├── server.rs         # Remote Service 服务端
      │   ├── client.rs         # Remote Service 客户端
      │   ├── scheduler.rs      # 远程 Compaction 调度
      │   ├── protocol.rs       # 通信协议定义
      │   ├── load_balancer.rs  # 负载均衡策略
      │   └── compaction_service.rs  # Server-side Compaction 服务
```

```
                    ┌───────────────────────┐
                    │   forst-rs-bridge     │  Layer 5
                    │   (C ABI 导出)         │
                    └───────────┬───────────┘
                                │
                    ┌───────────▼───────────┐
                    │   forst-rs-api        │  Layer 4
                    │   (适配 trait)         │
                    └───────────┬───────────┘
                                │
                    ┌───────────▼───────────┐
                    │   forst-rs-engine     │  Layer 3
                    │   (引擎核心)           │
                    └──┬────────┬───────────┘
                       │        │
          ┌────────────▼─┐  ┌──▼────────────┐
          │ forst-rs-    │  │ forst-rs-     │  Layer 2
          │ storage      │  │ storage       │
          │ (MemTable,   │  │ (SST, Cache,  │
          │  VersionSet) │  │  Bloom)       │
          └──────┬───────┘  └──────┬────────┘
                 │                 │
          ┌──────▼─────────────────▼────────┐
          │       forst-rs-io               │  Layer 1
          │       (FileSystem, AsyncIO)     │
          └──────────────┬──────────────────┘
                         │
          ┌──────────────▼──────────────────┐
          │       forst-rs-common           │  基础层
          │       (types, errors, utils)    │
          └─────────────────────────────────┘

中期/长期扩展 crate 依赖:

  forst-rs-deltajoin ─────→ forst-rs-engine + forst-rs-api
  forst-rs-remote-service ──→ forst-rs-engine + forst-rs-io
```

**依赖规则**：
- 上层只能依赖下层，不能反向依赖
- 同层 crate 之间不互相依赖
- `forst-rs-common` 不依赖任何 workspace 内其他 crate
- 扩展 crate（deltajoin、merge-service）依赖核心 crate，但核心 crate 不依赖扩展 crate

### 3.1 forst-rs-common

**职责**：公共类型定义、错误体系、工具宏、配置结构

```
forst-rs-common/
├── src/
│   ├── lib.rs
│   ├── error.rs          # Error/Result 类型，ErrorCode 枚举
│   ├── types.rs          # OpType, KeyRange, SequenceNumber, FileNumber
│   ├── config.rs         # EngineOptions, CfOptions, ReadOptions, WriteOptions

│   ├── arena.rs          # Bump allocator / Arena 分配器
│   └── metrics.rs        # 指标定义（Counter, Gauge, Histogram）
```

**外部依赖**：
| 依赖 | 版本 | 用途 |
|------|------|------|
| `thiserror` | 2.x | 错误派生宏 |
| `crc32fast` | 1.x | CRC32 校验 |
| `bytes` | 1.x | 字节缓冲区（Buf/BufMut trait） |

**核心类型**：

```rust
/// 操作类型
#[repr(u8)]
pub enum OpType {
    Put = 1,
    Delete = 2,
    Merge = 3,
}

/// 错误码（通过 C ABI 传递）
#[repr(i32)]
pub enum ErrorCode {
    Ok = 0,
    IoError = 1,
    Corruption = 2,
    NotFound = 3,
    NotSupported = 4,
    InvalidArgument = 5,
    MergeInProgress = 6,
    Busy = 7,
    ShutdownInProgress = 8,
}

/// ForSt-RS 统一错误类型
#[derive(thiserror::Error, Debug)]
pub enum Error {
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
    #[error("Data corruption: {0}")]
    Corruption(String),
    #[error("Not found: {0}")]
    NotFound(String),
    #[error("Invalid argument: {0}")]
    InvalidArgument(String),
    #[error("No merge operator configured")]
    NoMergeOperator,
}

pub type Result<T> = std::result::Result<T, Error>;
```

### 4.2 与 Flink 模块的关系

```
Flink StateBackend 体系:

  flink-statebackend-forst (现有 ForSt/RocksDB StateBackend)
      │
      ▼ 可选替换
  forst-rs-flink (ForSt-RS StateBackend)
      ├── state/         # AsyncKeyedStateBackend 实现
      ├── snapshot/       # Checkpoint 快照策略
      ├── restore/        # 恢复操作
      ├── deltajoin/      # DeltaJoin 本地化组件
      └→ forst-rs-java-bridge (FFM/JNI 桥接层)
```

**模块定位**：

- **短期**：`forst-rs-flink` 作为 `flink-statebackend-forst` 的可选替换方案，提供兼容的 Flink StateBackend 实现，通过 `forst-rs-java-bridge` 调用 Rust 引擎
- **中期**：`forst-rs-flink/deltajoin/` 提供 DeltaJoin 本地化支持，Lookup 在 Flink TaskManager 本地完成，利用 ForSt-RS 的 prefix_scan 能力进行高效查询
- **长期**：配合 `forst-rs-remote-service` crate，支持 Remote Merge 和 Server-side Compaction 场景
